2. Not implemented / present limitations 11 items

#AreaStatus and impact
1NOT DONEServer & databaseNo backend, API or database. Records live in this browser only, so other devices cannot see them. Clearing storage or exceeding the ~5 MB quota loses records silently.
2NOT DONELogin, roles & accessThe manager portal (/admin) opens without login. No admin/reviewer/branch roles or permissions; the reviewer is hard-coded as “Manager · Suresh”.
3NOT DONEReal SMS / OTPSMS is simulated and the OTP is shown on screen; expiry is displayed but not enforced on submit; the demo member has a fixed OTP. No gateway or delivery report.
4NOT DONEDocument verificationNo OCR, government-ID validation, face/liveness, duplicate or blacklist checks. The reviewer sees only the member photo and one legacy ID image; citizenship, selfie, national ID and other uploads are stored but not viewable or printed.
5NOT DONEMember notificationsNo SMS or email is sent on approval, rejection or printing, although the UI states the member was notified.
6NOT DONERejection / resubmissionA rejected member’s link shows only a status screen; there is no resubmit action or manager “reopen” control. A new submission overwrites the old one, with no history.
7NOT DONEReports, search & exportNo export (CSV/Excel/PDF), search, date/branch filter, pagination or activity/audit log. CSV exists for member import only.
8PARTIALFile handlingThe stated 5 MB limit is not enforced; uploaded PDFs are stored as a filename placeholder, not the file; large uploads can exhaust storage silently.
9NOT DONEPrivacy & retentionPersonal data and documents are stored unencrypted in the browser; no consent log beyond a checkbox, retention/deletion policy, backup or restore.
10NOT DONEKYM & integrationsNo institutional (company) onboarding fields; no core-banking, accounting or regulator integration; the branch list is fixed in code.
11NOT DONEQuality & deployment0 automated tests, no CI, error monitoring or production hosting; the system runs as a local Vite build only.
ReadinessThe end-to-end KYC journey is demonstrated and usable for evaluation (13 working modules; 0 automated tests). It is not ready for live member data: 5 core production items remain — server/database, authentication & roles, real SMS/OTP, document verification, and privacy/backup.
Next phase(1) Backend, database and document storage; (2) login, roles and audit log; (3) SMS gateway with enforced OTP expiry; (4) reviewer view of all 9 documents plus verification checks; (5) notifications, reports and export; (6) security hardening, backup and retention policy.
